# PT Web App 💪

A personal trainer client management web app for tracking clients, workouts, and progress.

## Features

- 👤 Client management (add, edit, view clients)
- 🏋️ Workout tracking and exercise logging
- 📈 Progress tracking (weight, measurements, PRs)
- 📅 Session scheduling
- 📊 Dashboard overview

## Tech Stack

- **Frontend**: HTML, CSS, Vanilla JavaScript
- **Hosting**: To be configured

## Getting Started

Open `index.html` in your browser to run the app locally.

## Project Structure

```
pt-web-app/
├── index.html          # Dashboard / main entry point
├── clients.html        # Client list and management
├── workouts.html       # Workout logging
├── progress.html       # Progress tracking
├── css/

├── js/
│   └── app.js          # Main application logic
└── README.md
```

No build step required — pure HTML/CSS/JS.
